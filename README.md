# EventCraft (Eventify Management System)

EventCraft is a comprehensive event management web application built with a modern full-stack architecture. It supports three main modules—Admin, Customer, and Employees—each tailored to streamline event operations.

## Key Modules

### Admin
- Log in and manage administrative access.
- Add employees and assign tasks.
- Monitor task status and update profiles.

### Customer
- Register, log in, and manage profiles.
- Select event themes and make payments.
- Track event progress and view recent bookings.

### Employees
- Manage assigned tasks.
- Upload work status updates.
